# FitClub — приложение клиента и приложение тренера

Аналог по функциям Mobifitness (клиент) и «Тренер 1С:Фитнес клуб» (тренер).
Один сервер, одна база SQLite, два приложения. Зависимостей нет.

## Запуск
Нужен Node.js 22.5 или новее.

    node server.js

- Клиент: http://localhost:3000/ — демо 79000000000 / 1234 (или «Регистрация»)
- Тренер: http://localhost:3000/#trainer — демо 79990000001 / 1234

База создаётся в `fitclub.db` с демо-данными. Удалите файл, чтобы начать заново.
Переменные: `PORT`, `DB_PATH`. На телефоне открывается как приложение
(«Добавить на главный экран»).

## Что умеет
Клиент: выбор клуба, регистрация и вход, расписание на 14 дней с фильтром,
запись/отмена (не позже чем за 2 ч), лист ожидания с автозаписью при
освобождении места, персональные к тренеру по свободным слотам, магазин
абонементов и пакетов, заморозка/разморозка, счёт и операции, клубная карта
и история посещений, новости, уведомления, удаление аккаунта.

Тренер: расписание по дням (групповые + персональные, несколько клубов),
отметка посещений, гость без записи, персональные — провести/неявка/
отменить/перенести со списанием из пакета, клиенты с поиском, заметки,
запись клиента, предложение пакета, статистика и начисления за период.

## Что подключить перед реальным запуском
- Оплата: `/api/topup` сейчас зачисляет деньги без оплаты (тестовый режим).
  Подключите ЮKassa или CloudPayments и зачисляйте по их webhook.
- Вход по SMS: сейчас телефон + пароль. Для SMS-кода нужен провайдер (SMS.ru и т.п.).
- Push-уведомления: сейчас уведомления внутри приложения.
- QR-карта рисуется по номеру клиента; для турникета нужен свой сканер на ресепшене.
- Ставки зарплаты тренера (1200/900 ₽) заданы в `server.js`.
- Интеграции с самой 1С нет — это отдельная система.
