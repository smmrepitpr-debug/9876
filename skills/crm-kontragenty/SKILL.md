# CRM контрагентов

Цель: вся переписка с контрагентом → резюме → задачи → продажа и повторные продажи.
По каждому клиенту система всегда отвечает на 4 вопроса:
1. **Где мы сейчас?** (стадия + одна строка)  2. **Что дальше?** (шаг + срок)  3. **Кто делает?**  4. **Что ещё можно продать?**

## Где данные
Файл `CRM_контрагенты.xlsx` (у Юли / в рабочей папке; в git не кладём — там контакты):
- **Клиенты** — одна строка на контрагента, ID вида К-001. Поля: контрагент, проект, сегмент, город, ЛПР, контакты, канал, источник лида, стадия, где мы сейчас, что дальше, кто делает, срок, потребность, возражения и как отработали, сумма/условия, что ещё продать, последнее касание, касаний всего, риски, файлы.
- **Касания** — каждый контакт отдельной строкой: дата, ID, канал, кто, тип, выжимка, договорились, новая потребность/возражение, ссылка.
- **Задачи** — следующий шаг после каждого касания: что, кто, срок, статус.
- **Допродажи** — что ещё предложить и когда.
- **Метрики** — считаются формулами.
Подробная ветка по контрагенту — карточка по шаблону `ШАБЛОН_карточка_и_сводки.md`.

Стадии: лид → контакт → переговоры → КП → договор → оплата → повтор (+ отказ, пауза).

## Порядок работы с каждой новой перепиской / звонком
1. Определи контрагента (город + имя/название). Нет в CRM — заведи новую строку и ID.
2. Добавь строку в **Касания**: выжимка 1–3 предложения, что договорились, новая потребность или возражение.
3. Обнови в **Клиенты**: стадию, «где мы сейчас», «что дальше», срок, сумму/условия, ЛПР, потребность, возражения.
4. Поставь **задачу** на следующий шаг (что, кто, срок). Касание без следующего шага — ошибка.
5. Если видна возможность — запиши **допродажу**.
6. Сравни с прошлыми касаниями: если контрагент в разных каналах называет разные цены/условия — запиши в «Риски» и сообщи пользователю.
7. Подготовь, если нужно, черновик ответа контрагенту — отправляет пользователь сам.

## Правила
- Только факты из присланных материалов. Нет данных — поле пустое, не выдумывать.
- Звонки — только с записью/расшифровкой; пересказ по памяти помечать «со слов».
- Каждое касание → движение к сделке; фиксировать потребности и возражения — это топливо для допродаж.
- Неактивные более 14 дней → стадия «пауза» + задача на реактивацию.
- Метод и база — внутри команды, никому не передавать.

## Сводки
**Ежедневно**: касаний, новых контактов, кто сдвинулся по стадиям (было → стало), просроченные задачи, главное за день, 3 шага на завтра.
**Еженедельно**: воронка по стадиям, конверсия и где теряем, сумма в работе, средний чек, причины отказов, допродажи на неделю, реактивация, задачи в срок %.
Цифры — только из CRM.

## Метрики (для аналитики, когда наберётся база 3–4 недели)
Касаний до сделки · конверсия по стадиям · средний чек · повторные продажи % · срок от лида до оплаты · причины отказов · сумма в работе (pipeline) · задачи в срок %.

## Мессенджеры
Прямого коннектора к личным Telegram/WhatsApp нет. Источники: экспорт чата Telegram Desktop (JSON, без медиа), экспорт WhatsApp (.txt), скрины. Когда появится коннектор или локальная синхронизация чатов по папкам — читать оттуда.
