# Фитнес Плаза — LED-ролик 5:1 (3000×600, 30 fps, 13,9 с, без звука)

Анимация на чистом HTML Canvas + JS (без React и сборки), рендер покадрово через Playwright → ffmpeg.

## Файлы
- `index.html` — вся анимация. Откройте в Chrome — играет по кругу (пробел — пауза, ← → — по кадру).
  Другой размер: `index.html?w=3600&h=600`.
- `render.mjs` — рендер в MP4 (H.264, CRF 20, yuv420p, без звука).
- `fonts/` — Rubik (вариативный 300–900, кириллица + латиница), подключён локально.
- `logo.png` (необязательно) — положите настоящий логотип клуба рядом с index.html, он заменит нарисованный силуэт.

## Запуск рендера (Windows / Mac / Linux)
Нужны Node 18+ и ffmpeg в PATH.
```
npm i playwright
npx playwright install chromium
node render.mjs                 # out/plaza-3000x600.mp4
node render.mjs 3600 600        # out/plaza-3600x600.mp4
node render.mjs 2400 600        # out/plaza-2400x600.mp4
node render.mjs 3000 600 6.5    # один PNG-кадр на 6,5 с — для проверки
CRF=16 node render.mjs          # качество выше (файл больше)
```

## Как устроено
- Все размеры в единицах `u = H / 600`; ширина влияет только на раскладку по горизонтали.
- Тайминг сцен: `SCENES = [2.0, 2.8, 2.8, 3.3, 3.0]` в начале скрипта.
- Эффекты: RGB-расслоение (красный/голубой слои в режиме lighter), слова выезжают снизу из-под маски,
  тряска камеры на ударе + наезд 1.0→1.06 (фон с параллаксом), диагональный блик, переходы полосами
  белая/голубая/синяя, неоновые кольца, частицы, перспективная сетка, виньетка, сканлайны, REC и «PLAZA · УХТА».
- Эмодзи — Noto Color Emoji (на Windows подставится Segoe UI Emoji).
