# «Команда» — 4 вертикальных моушн-ролика 9:16 (1080×1920, 30 fps, 24 с)

| V | Ролик | Призыв |
|---|---|---|
| 1 | Не просто CRM | ПОКАЖЕМ ЗА 10 МИНУТ → |
| 2 | Клиент записался сам | ПОДКЛЮЧИ СВОЮ СЕКЦИЮ → |
| 3 | Своё приложение у клуба | ХОЧУ ТАК ЖЕ → |
| 4 | Мы рядом, а не колл-центр | ПОЗВОНИТЕ НАМ → |

Чистый HTML Canvas + JS. `engine.js` — общий стиль и эффекты, `videos.js` — сценарии (тексты, тайминги).

## Посмотреть
Откройте `index.html?v=1` (…`v=4`) в Chrome. Пробел — пауза, ← → — по кадру.

## Рендер в MP4
Нужны Node 18+ и ffmpeg.
```
npm i playwright
npx playwright install chromium
V=1 node render.mjs        # out/komanda-1-ne-prosto-crm-1080x1920.mp4
V=2 node render.mjs
V=3 node render.mjs
V=4 node render.mjs
V=3 node render.mjs 1080 1920 6   # PNG-кадр на 6-й секунде
```
Windows (cmd): `set V=2 && node render.mjs`.

## Музыка
`beat.wav` — синтезированный бит (112 BPM, без слов, свой — без лицензий), подмешивается тихо (−9 дБ) с затуханием в конце.
Чтобы поставить свою дорожку — положите `music.mp3` рядом: она возьмётся вместо beat.wav.
