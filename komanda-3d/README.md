# «Команда» — 4 ролика 9:16 в стиле премиального 3D + продуктовой UI-анимации
HTML/CSS 3D (перспектива, объёмный телефон, формы с тенями), один управляемый таймлайн, курсор с кликами по реальным элементам.
- Посмотреть вживую: `index.html?v=1` … `v=4` (Chrome).
- Рендер: `npm i playwright && npx playwright install chromium`, затем `V=1 node render.mjs` (нужны ffmpeg и python3 + numpy). Звук (музыка + SFX) — `audio.py`.
- Озвучка женским голосом: `pip install edge-tts && python voice.py` → `out/…-voice.mp4`.
- Тексты для постов: `ОПИСАНИЯ_к_постам.md`.
Данные в интерфейсе (имена, цифры) — демонстрационные.
