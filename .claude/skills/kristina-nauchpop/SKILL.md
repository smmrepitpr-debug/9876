# Научпоп-ролики Кристины Рэй

Все файлы лежат в `kristina/`. Фото и вырезки Кристины только локально (в git они в .gitignore), в репозиторий не добавлять.

## Структура ролика (25 с, 30 к/с)
- 0–2.5 с крючок: вопрос или факт, героиня въезжает.
- 2.5–8.3 с «почему»: схема-фигурка, позвоночник кривится, мышцы, стрелки, иллюстрация из `temy/web`.
- 8.3–18.2 с «что делать»: 3 действия (иконка, номер, подпись; фигурка или вырезка).
- 18.2–22.2 с клуб: «Онлайн-клуб «Здоровая спина», 15 минут в день, Напиши «СПИНА» мне в личные сообщения».
- 22.2–25 с: «Если боль сильная или есть онемение, обратись к врачу», затухание.

## Правила
- Это научпоп, не медицина: без диагнозов, без «вылечить/убрать грыжу», без выдуманных цифр, без цены, без чужих брендов.
- Палитра: молочный #F3EEE7, чернила #2A2A2A, синий #6C8EAD, беж #D9CFC3, мягкая терракота #C48B7C для «напряжено». Шрифты Montserrat и Cormorant Garamond курсив.
- Основной текст от 64 px, не закрывает героиню. Лицо и пропорции Кристины не менять.
- Картинки из архива тем: только с указанной лицензией, с подписью автора в кадре (CC BY) или общественное достояние.
- Вырезки с повреждёнными предметами (например k19, дыра в мяче) не использовать. Надпись бренда на мяче в `k21` уже закрашена (`cut/kristina_07_clean.png`).

## Как сделать новый ролик
1. Добавить объект в массив `VIDEOS` в `np-videos.js`: `hook` (героиня и 2–3 строки), `a` и `b` (схема: `keys` или `loop` из поз `POSES`, `props`, `muscles`, `arrows`, `labels`, `card`), три `acts`, `clubHero`, при необходимости `disc`.
2. Новые позы фигурки добавляются в `POSES` в `np.js` (точки H, N, C, P, S, E, W, K, F).
3. Новую героиню вырезать: `python3 cut.py 05 07 ...` (rembg, модель isnet-general-use) в `cut56/`, посмотреть вырезки на сером фоне.
4. Проверка кадров: `VS=6 node sheet.mjs`, затем смотреть картинки в `/tmp/sheet`.
5. Рендер: `V=6 PAGE=nauchpop.html node render.mjs` (нужны playwright, ffmpeg, python3 с numpy). Звук собирается автоматически (`audio.py`), без вокала.
6. Написать подпись (до 600 знаков, 3–5 хэштегов) и первый комментарий «напиши СПИНА» в `ПОДПИСИ_к_роликам.md`.
7. Показать превью-кадры 0, 3, 10, 20 с и подтвердить, что текст не закрывает героиню.
